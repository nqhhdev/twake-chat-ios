# Concepts
* [App Group](app-group.md) - A container and Keychain scope that an app and its extensions can both read and write.
* [Coordinator](coordinator.md) - The object that owns navigation for one flow and creates its view models.
* [Layer](layer.md) - A group of code with one role and a fixed list of modules it may import.
* [Liquid Glass](liquid-glass.md) - The translucent material and look introduced with iOS 26; absent on iOS 18.
* [NSE](notification-service-extension.md) - Notification Service Extension: a separate iOS process that can change a notification before it is shown.
* [Proxy](proxy.md) - A MatrixData type that wraps one Matrix SDK object and exposes it through a Domain protocol.
* [Push Gateway](push-gateway.md) - The server that receives push requests from the homeserver and forwards them to APNs.
* [Recovery Key](recovery-key.md) - The secret a user enters on a new device to unlock their encryption keys stored on the server.
* [Repository](repository.md) - A Domain protocol that gives features one kind of data without saying where it comes from.
* [Sliding Sync](sliding-sync.md) - The Matrix sync method that loads only the rooms in view; required by the Matrix Rust SDK.
* [View Model](state-holder.md) - The @Observable object that holds one screen's state and actions.
