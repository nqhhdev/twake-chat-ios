# Agent instructions

Read [.okf/index.md](.okf/index.md) first and follow the links you need. It is the only source of project knowledge.

- Keep the rules in [.okf/engineering/constraints.md](.okf/engineering/constraints.md).
- Follow the ADRs in [.okf/adr/](.okf/adr/index.md). If a task conflicts with one, report the conflict instead of working around it.
- Run the checks in [.okf/workflows/build.md](.okf/workflows/build.md) and [.okf/workflows/test.md](.okf/workflows/test.md) before finishing.
- After changing `.okf/`, run `python3 .okf/tools/okf.py --check`.
